# lihkg-snapshot-viewer

View a scraped LIHKG thread (scraped with [lihkg-scraper](https://github.com/lhfmartin/lihkg-scraper)) in a human-readable manner

## How To Use The Application

1. Go to https://lhfmartin.github.io/lihkg-snapshot-viewer/ (or http://localhost:5173/lihkg-snapshot-viewer if you have the [local development server running](#how-to-start-the-development-server))
1. Click the "CHOOSE FOLDER" button and choose the folder
   - Dragging and dropping the folder onto the button also works

## How To Start The Development Server

```bash
pnpm install
pnpm dev
```
